# solar-system
A simple representation of Solar system.

# why this is helpful ?

this is mainly for kids who are struggling to learn about this solar system. this will surely upgrade from just solar system to whole univers :D.

# to use it 

you can clone this repo and open it with your code editor (i prefer vs code) then at extensions install live server extenstion then right click on the index.html then open with live server..
